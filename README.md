# *Приложение для анализа транзакций*

## Цель

Это первый ***курсовой проект***. Разрабатывается для закрепления навыков полученных во время учёбы.
Предполагается, что данное приложение взаимодействует с вэб-страницей при помощи json-формата файлов.   

## Установка

* Скопировать репозиторий на ПК:
`git clone https://github.com/Nekrontir/SkyPro_course_project.git ` 
* В проекте используется Poetry, для установки виртуального окружения и всех зависимостей 
необходимо использовать команды:
`poetry install`, `poetry sync`
* стереть ***.example*** у шаблона .env.example, внести необходимые для работы API-ключи.

## Использование

Выполнить установку, разместить файл который необходимо обрабатывать в паку `data` в корневой директории.
Настройки пользователя хранятся в файле `user_settings.json`в корневой директории приложения.

## Содержание проекта

Проект содержит модули:
1. views.py - содержит функции для формирования функции главной вэб-страницы
2. utils.py - содержит функции для получения данных из файлов 
3. services.py - содержит функции сервисы для обработки данных с транзакциями
4. decorators.py - содержит функцию декоратор для отчётов 
5. reports.py - содержит функцию создания отчёта
6. config.py - содержит пути для работы с файлами и записи логов

## Тесты

Репозиторий содержит тесты. Используется фреймворк PyTest.
Тестами покрыты все функции (покрытие примерно 80+%).
Для запуска тестов с автоматическим формированием результатов необходимо выполнить команду:
`pytest --cov=src --cov-report=html`

## Логирование

Логирование ведётся для каждого модуля. Запись логов производится в корневую папку logs.
